# Руководство программиста

## 1. Назначение программы

Программа **Hoctopus** (Friday Helper) предназначена для персонального помощника на смартфоне: учёт задач и напоминаний, заметки, чат с ИИ-ассистентом по голосу и тексту, будильники по голосовой команде, погода, курсы валют и криптовалют, настройка внешнего вида и безопасности (блокировка, биометрия).

## 2. Требования к оборудованию и ПО

Для работы приложения необходим смартфон или планшет со следующей конфигурацией:

- **ОС:** Android 7.0 (API 24) и выше, рекомендуется Android 10 и выше;
- **ОЗУ:** не менее 2 ГБ;
- **Память:** не менее 100 МБ для установки приложения;
- **Экран:** разрешение не менее 320×480 px;
- **Дополнительно:** доступ в Интернет (для чата с ИИ, погоды, курсов валют); микрофон — для голосового ввода и голосового пробуждения (по желанию).

## 3. Состав проекта

В папке с проектом **project_smartphone** (или на носителе) находятся:

### 3.1. Корень проекта

- **build.gradle.kts** — корневая конфигурация Gradle (подключение плагинов);
- **settings.gradle.kts** — настройки проекта и модулей;
- **gradle.properties** — свойства Gradle;
- **libs.versions.toml** — версии зависимостей (каталог версий);
- папка **app** — основной модуль приложения;
- папка **gradle** — обёртка Gradle (wrapper).

### 3.2. Модуль app (приложение)

- **app/build.gradle.kts** — конфигурация сборки приложения (SDK, зависимости);
- **app/proguard-rules.pro** — правила обфускации для Release;
- **app/src/main/AndroidManifest.xml** — манифест (разрешения, компоненты приложения);
- **app/src/main/java/com/example/friday_helper/** — исходный код на Kotlin:
  - **MainActivity.kt** — главный экран (погода, чат, меню);
  - **WelcomeActivity.kt**, **WelcomeOctopusActivity.kt**, **EntryActivity.kt** — экраны приветствия и входа;
  - **FridayHelperApp.kt** — класс приложения;
  - **alarm/** — будильники (AlarmScheduler, AlarmReceiver);
  - **chat/** — чаты с ИИ (OpenAiClient, ChatRepository, БД чатов);
  - **notes/** — заметки (NotesActivity, NoteEditorActivity, NotesRepository);
  - **tasks/** — задачи и напоминания (TasksActivity, TasksRepository, TaskEntity, TaskNotificationScheduler);
  - **rates/** — курсы валют и криптовалют (FiatRatesActivity, CryptoRatesActivity, FiatToCryptoActivity, клиенты API);
  - **settings/** — настройки (внешний вид, персонализация, безопасность, разрешения, голосовое пробуждение);
  - **security/** — блокировка и безопасность (LockActivity, SecuritySession, SecurePrefs);
  - **weather/** — погода (WeatherClient);
  - **ui/** — кастомные представления (TentaclesView, VoiceWavesView);
- **app/src/main/res/** — ресурсы:
  - **layout/** — разметка экранов (XML);
  - **values/** — строки (strings.xml), цвета (colors.xml), темы (themes.xml);
  - **drawable/** — иконки и графика;
  - **xml/** — правила резервного копирования и извлечения данных.

Исполняемый результат после сборки: **app/build/outputs/apk/debug/app-debug.apk** (или **release/app-release.apk** при сборке Release). Установка на устройство возможна через Android Studio (Run) или копирование APK на устройство.

## 4. Установка и запуск

1. **Установка на устройство из Android Studio:** открыть проект в Android Studio, подключить устройство по USB (с включённой отладкой по USB) или запустить эмулятор, нажать Run (зелёный треугольник) или выполнить **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
2. **Установка из APK:** скопировать **app-debug.apk** (или **app-release.apk**) на устройство и открыть файл, разрешив установку из неизвестных источников при запросе системы.
3. **Первый запуск:** приложение запросит необходимые разрешения (Интернет, уведомления, микрофон и т.д. — в зависимости от используемых функций). Для чата с ИИ в разделе «Настройки → Дополнительно» нужно указать API-ключ OpenRouter (или иного совместимого провайдера).

База данных (SQLite через Room) создаётся автоматически при первом запуске в каталоге данных приложения. Отдельная установка СУБД не требуется.

## 5. Пользователи и данные

Приложение рассчитано на одного пользователя устройства. Учётные данные блокировки (PIN/пароль, биометрия) хранятся локально в защищённом хранилище (EncryptedSharedPreferences). Чаты, задачи и заметки хранятся в локальных базах Room (файлы БД в каталоге приложения). API-ключ ИИ сохраняется в настройках приложения (рекомендуется хранить его в защищённом хранилище при доработке).

## 6. Доработка и модернизация

Для разработки и изменения проекта необходимы:

- **Android Studio** (рекомендуется последняя стабильная версия) — среда разработки для Android;
- **JDK 17** (или версия, указанная в настройках проекта);
- **Android SDK** с API 24 и выше (целевой API задаётся в **app/build.gradle.kts**);
- навыки работы с **Kotlin**, **Android SDK**, **Room**, **ViewBinding**, **XML-разметкой** и при необходимости с **REST API** (погода, курсы, OpenRouter).

Для изменения клиентской части откройте папку проекта в Android Studio (**File → Open** и выберите папку **project_smartphone**). Сборка и запуск выполняются через меню **Build** и **Run**. Зависимости подключаются в **app/build.gradle.kts** и в **libs.versions.toml**.

## 7. Полное удаление приложения

Для удаления приложения с устройства:

1. **Настройки → Приложения → Hoctopus** (или «Friday Helper») → **Удалить** (или перетащить иконку в «Удалить» на главном экране).
2. После удаления все локальные данные приложения (базы чатов, задач, заметок, настройки) удаляются системой. Резервные копии Android (если включены) могут хранить часть данных до следующей переустановки — при необходимости их можно очистить в настройках резервного копирования.

Для удаления только исходного кода с ПК удалите папку проекта **project_smartphone**.
