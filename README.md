# Friday Helper — голосовой AI-ассистент для Android

**Friday Helper** — это мобильное приложение для голосового управления задачами, напоминаниями и звонками с использованием искусственного интеллекта. Ассистент распознаёт естественную речь, анализирует намерения через AI (OpenRouter / OpenAI) и выполняет действия: создаёт задачи, устанавливает напоминания, ищет контакты и инициирует звонки.

## Основные возможности

- 🎙️ **Голосовое распознавание** — запуск команд через удержание кнопки микрофона (SpeechRecognizer).
- 🧠 **AI-обработка команд** — распознавание интентов с помощью OpenRouter (поддерживаются модели GPT, Claude, Llama).
- ✅ **Управление задачами** — создание, просмотр, выполнение и удаление задач.
- ⏰ **Напоминания** — установка напоминаний с привязкой ко времени и уведомлениями.
- 📞 **Звонки по имени контакта** — нечёткий поиск контакта в адресной книге и автоматический вызов.
- 💬 **Текстовый чат** — альтернативный способ взаимодействия с ассистентом.
- 🌙 **Тёмная и светлая темы** — переключение оформления интерфейса.
- 🔐 **Безопасное хранение API-ключа** — ключ хранится в локальных настройках, не попадает в Git.

## Технологии

- Язык:** Kotlin
- Android SDK: API 32+ (Android 12+)
- Распознавание речи: Android SpeechRecognizer
- AI-интеграция: OpenRouter API (совместим с OpenAI)
- Локальное хранилище: DataStore / Preferences
- База данных задач: Room (SQLite)
- Асинхронность: Kotlin Coroutines
- Сеть: Retrofit / OkHttp

## Установка и запуск

### Требования
- Android Studio Hedgehog (2023.1.1) или новее
- Android SDK с API 32+
- Устройство или эмулятор с Android 12+

### Шаги для запуска

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/jeb-fifiv/Friday_Helper.git
Откройте проект в Android Studio.

Выберите File → Open → укажите папку с проектом.

Настройте API-ключ OpenRouter:

Зарегистрируйтесь на OpenRouter и получите API-ключ.

В Android Studio создайте файл local.properties в корне проекта (если его нет).

Добавьте строку (без кавычек):

text
OPENROUTER_API_KEY=ваш_ключ_здесь
Либо введите ключ в первом диалоге при первом запуске приложения.

Соберите и запустите приложение:

Подключите устройство по USB или запустите эмулятор.

Нажмите зелёную кнопку Run (Shift+F10).

Сборка APK
Отладочная версия (для тестирования)
Build → Build Bundle(s) / APK(s) → Build APK(s)

APK будет в app/build/outputs/apk/debug/

Подписанная версия (для публикации)
Build → Generate Signed Bundle / APK

Создайте ключ подписи (keystore) или выберите существующий

Выберите release сборку и нажмите Finish

APK появится в app/release/
